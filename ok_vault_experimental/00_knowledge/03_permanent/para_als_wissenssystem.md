# [[para_als_wissenssystem]]

## Summary

PARA ist das effektivste universelle System zur Organisation digitalen Wissens, weil es nicht nach **Thema** (wie die meisten), sondern nach **Handlungsrelevanz** ordnet. Dadurch bleibt das System immer mit der aktuellen Lebensrealität synchron.

## Key Concepts

### Die zentrale Einsicht

> Das Gehirn ist zum *Denken* da – nicht zum *Erinnern*.  
> Ein externes System übernimmt das Erinnern, damit das Gehirn freier denken kann.

### Warum PARA anderen Systemen überlegen ist

| Problem | Themen-Ordner | PARA |
|---|---|---|
| Information nicht mehr relevant | Bleibt im System 🔴 | → Archiv ✅ |
| Projekt abgeschlossen | Orphaned Folder 🔴 | → Archiv ✅ |
| Neues Thema startet | Wo anlegen? 🔴 | Projekt oder Bereich? ✅ |
| System wächst unkontrolliert | Chaos 🔴 | Max. 4 Kategorien ✅ |

### Die vier Kategorien im Zusammenspiel

```
Projekte ──abgeschlossen──→ Archiv
    ↑                          ↑
  aus Bereichen              aus Bereichen
  entstanden                 aus Ressourcen

Bereiche ──eingestellt──→ Archiv
    ↓
  Ressourcen (Wissen bleibt)

Ressourcen ──veraltet──→ Archiv
```

### PARA + Zettelkasten = vollständiges PKM-System

PARA allein strukturiert *Ablage*. Zettelkasten strukturiert *Denken*.
Kombiniert entsteht ein System, das:
- Wissen **findet** (PARA)
- Wissen **verknüpft** (Zettelkasten)
- Wissen **anwendet** (CODE-Methode)
