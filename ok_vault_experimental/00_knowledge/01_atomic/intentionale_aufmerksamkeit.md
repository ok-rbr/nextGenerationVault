# [[intentionale_aufmerksamkeit]]

## Key Concepts

> „Paying attention on purpose."  
> — Jon Kabat-Zinn

Intentionale Aufmerksamkeit ist die Fähigkeit, **bewusst zu wählen, womit ich meine Energie gebe** – und dabei zu bleiben.

---

### Das Problem: Aufmerksamkeits-Fragmentierung

Das Gehirn **kann kein Multi-Tasking**. Was es tut, ist schnelles Umschalten – mit jedem Switch entstehen Kosten:

```
Aufgaben-Switch-Kosten:
  • Kognitive Reibung beim Umschalten: 15–23 min Wiederankommzeit
  • Flüchtigkeitsfehler durch "divided attention"
  • Energie-Erschöpfung schneller als bei fokussierter Arbeit
```

### Mono-Tasking als Gegenprinzip

**Eine Aufgabe. Ein Meeting. Ein Moment.**

| Multi-Tasking | Mono-Tasking |
|---|---|
| Slack + Call + Code | Call = nur Call |
| Meeting + E-Mails | Meeting = nur Meeting |
| Task + Task | Task = bis Abschluss |
| Schnell + flüchtig | Langsamer + tiefer |

### Flow als Zielzustand

Flow (Csikszentmihalyi) entsteht, wenn:
- Die Aufgabe herausfordernd, aber nicht überwältigend ist
- Externe Unterbrechungen minimiert sind
- Eine klare Intention gesetzt wurde

→ Setup für Flow: [[achtsamkeit_task_pause]] (Vor-Ritual)

### Praktische Strategien im Vault-Kontext

```
1. Fokusblock definieren
   └─ Task-Note: Feld `fokus_block: "09:00–10:00"`

2. Kontext-Trennung
   └─ Nur relevante Notes offen; unrelated tabs schließen

3. Notification-Protokoll
   └─ Meeting/Task beginnt → Benachrichtigungen aus

4. Energie-Puffer
   └─ Zwischen deep-work Blöcken: 5 min Micro-Break
      (Aufstehen, Atemzüge, kein Screen)

5. Ende klar definieren
   └─ Task endet mit Abschluss-Ritual → [[achtsamkeit_task_pause]]
```

### Die Frage vor jedem Start:

> **„Ist das, was ich gleich tue, meine bewusste Wahl – oder reagiere ich gerade nur?"**
