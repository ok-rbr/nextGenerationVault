# [[para_projekte]]

## Key Concepts

Ein **Projekt** in PARA ist jede Aktivität, die:
1. Ein **konkretes Ziel** hat (ein messbares Ergebnis)
2. Eine **Deadline** hat (oder einen definierten Abschluss)
3. **Aktiv bearbeitet** wird

### Abgrenzung: Projekt vs. Bereich

Dies ist die wichtigste Unterscheidung in PARA:

| Merkmal | Projekt | Bereich |
|---|---|---|
| Ziel | Klar definiert ✅ | Laufend ➿ |
| Deadline | Ja ✅ | Nein ➿ |
| Abschluss | Möglich ✅ | Nie "fertig" ➿ |
| Beispiel | „Website launchen" | „Gesundheit pflegen" |
