# [[para_bereiche]]

## Key Concepts

Ein **Bereich** (Area of Responsibility) in PARA ist ein Lebens- oder Arbeitsbereich, der:
1. **Keinen Endpunkt** hat – er wird nie „fertig"
2. Einen **Standard** aufrechterhalten soll
3. **Langfristige Verantwortung** trägt

> „Areas have standards to maintain, not outcomes to achieve."

### Beispiele für Bereiche

| Lebensbereich | Arbeitsbereich |
|---|---|
| Gesundheit | Teamführung |
| Finanzen | Technisches Know-how |
| Familie | Kundenpflege |
| Weiterbildung | Compliance |

### Abgrenzung: Bereich vs. Ressource

| Merkmal | Bereich | Ressource |
|---|---|---|
| Verantwortung | Aktiv ✅ | Passiv 📚 |
| Standard halten | Ja ✅ | Nein |
| Nur für mich | Ja ✅ | Auch für andere 📤 |
