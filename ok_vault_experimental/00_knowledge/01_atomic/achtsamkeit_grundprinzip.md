# [[achtsamkeit_grundprinzip]]

## Key Concepts

> „Between stimulus and response there is a space.  
> In that space is our power to choose our response."  
> — Viktor Frankl

**Der Raum zwischen Reiz und Reaktion** ist das Kernprinzip jeder Achtsamkeit im Arbeitsalltag.

### Was ist der „Reiz" im Arbeitsalltag?

```
Reize (Stimulus)            Typische Reaktion (Autopilot)
──────────────────────────────────────────────────────────
Neues Task taucht auf    →  Sofort anfangen, ohne Ziel
Meeting startet          →  Halbpräsent, Gedanken woanders
Kollege spricht          →  Bereits die Antwort formulieren
Aufgabe abgeschlossen    →  Sofort nächste Aufgabe beginnen
```

### Was ist die Pause?

Die Pause ist nicht Verzögerung – sie ist **bewusste Wahl**.

```
[Reiz] ──→ 😤 Autopilot-Reaktion
        ↓
   [PAUSE: 1–3 Atemzüge + 1 Frage]
        ↓
[Reiz] ──→ 🎯 Intentionale Antwort
```

### Die Pause im Vault-Kontext

| Kontext | Pause-Moment | Kernfrage |
|---|---|---|
| Task beginnt | Vor dem ersten Klick | „Was ist mein Ziel?" |
| Task läuft | Wenn Energie sinkt | „Bin ich noch auf Kurs?" |
| Task endet | Vor dem Schließen | „Was wurde wirklich getan?" |
| Meeting beginnt | Vor dem ersten Wort | „Warum bin ich hier?" |
| Meeting läuft | Nach jedem Beitrag | „Was wurde gerade gesagt?" |
| Meeting endet | Letzte 2 Minuten | „Was ist meine Action?" |
