# [[para_methode]]

## Key Concepts

PARA ist ein universelles Organisationssystem für digitales Wissen, entwickelt von **Tiago Forte** (→ [[building_a_second_brain]]).

**PARA** = **P**rojects · **A**reas · **R**esources · **A**rchive

```
Alle digitalen Inhalte fallen in genau eine der vier Kategorien:

  P – Projekte     → zeitlich begrenzt, klares Ziel
  A – Bereiche     → dauerhaft, kein Enddatum
  R – Ressourcen   → Referenz, thematisch
  A – Archiv       → inaktiv, aber auffindbar
```

### Kernprinzip: Actionability

PARA ordnet nicht nach **Thema**, sondern nach **Handlungsrelevanz**:

> „Organize for action, not by topic."

| Kategorie | Actionability | Zeithorizont |
|---|---|---|
| [[para_projekte\|Projekte]] | 🔴 Sofort aktiv | Wochen–Monate |
| [[para_bereiche\|Bereiche]] | 🟡 Laufend aktiv | Unbegrenzt |
| [[para_ressourcen\|Ressourcen]] | 🔵 Bei Bedarf | Dauerhaft |
| [[para_archiv\|Archiv]] | ⚪ Inaktiv | Historisch |

### Wichtige Regel: Jedes Item in genau einer Kategorie

Kein Ordner-Chaos, kein Doppeln – jede Notiz, jedes Dokument gehört zu exakt einer PARA-Kategorie.
