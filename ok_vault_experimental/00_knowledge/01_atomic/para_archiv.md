# [[para_archiv]]

## Key Concepts

Das **Archiv** in PARA ist der Aufbewahrungsort für alles, was aktuell **nicht aktiv** genutzt wird – aber eines Tages wieder relevant werden könnte.

> „The Archive is not a trash bin. It's a treasury."

### Was kommt ins Archiv?

| Quelle | Beispiel |
|---|---|
| Abgeschlossene **Projekte** | Migrationsprojekt fertiggestellt |
| Eingestellte **Bereiche** | Freelance-Tätigkeit aufgegeben |
| Veraltete **Ressourcen** | Dokumentation einer deprecated API |

### Die Kraft des Archivs

Das Archiv löst das größte Problem der Wissensorganisation:

**Ohne Archiv**: Löschen (Wissen verloren) ODER behalten (System überfüllt)
**Mit Archiv**: Beides – aus dem Sichtfeld, aber nicht verloren

### Archivieren ≠ Löschen

```
Projekt abgeschlossen
        ↓
  Ins Archiv (04_archive/)
  ├── Kontext bleibt erhalten
  ├── Suchbar
  └── Wiederbelebbar bei Bedarf
```

