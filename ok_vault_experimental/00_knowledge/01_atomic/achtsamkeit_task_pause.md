# [[achtsamkeit_task_pause]]

## Key Concepts

Eine Aufgabe ohne **Intention** ist Beschäftigung. Eine Aufgabe ohne **Reflexion** ist verlorenes Lernen.

Das **3-Phasen-Ritual** macht eine Aufgabe zu einer bewussten Handlung.

---

### 🟢 VOR der Aufgabe – Intention setzen

> *„Was will ich mit dieser Aufgabe erreichen?"*

**3 Fragen (30 Sekunden):**

```
1. Was ist das konkrete Ziel dieser Aufgabe?
2. Was brauche ich, um anzufangen? (Info, Fokus, Material)
3. Was könnte mich ablenken – und wie gehe ich damit um?
```

**Im Vault**: Diese Fragen beim Öffnen/Erstellen eines Task-Notes notieren.

```yaml
# Beispiel: Task-Frontmatter Ergänzung
intention: "Azure Pipeline Stage 2 deploybar machen"
fokus_blocker: "Slack ausschalten, 60 min Fokusblock"
```

---

### 🟡 WÄHREND der Aufgabe – Präsenz halten

> *„Bin ich noch auf Kurs?"*

**Mikro-Pause alle 25–30 Minuten (Pomodoro-Ankerpunkt):**

```
1. Was habe ich gerade getan?
2. Entspricht das noch meinem Ziel?
3. Was ist der nächste konkrete Mini-Schritt?
```

Wenn die Antwort auf Frage 2 „Nein" ist: **Kurz stoppen, neu ausrichten** – nicht einfach weiterarbeiten.

---

### 🔴 NACH der Aufgabe – Reflexion schließen

> *„Was wurde wirklich getan?"*

**3 Fragen (2 Minuten):**

```
1. Was wurde konkret erreicht / abgeschlossen?
2. Was bleibt offen – und wo wird es festgehalten?
3. Was habe ich gelernt oder erkannt?
```

**Im Vault**: `summary`-Feld und offene Punkte als neue Tasks im Projekt anlegen.

---

### Das Ritual im Überblick

```
[Task öffnen]
     ↓
🟢 Intention (30 sek) → Ziel klar?
     ↓
🟡 Arbeit + Mikro-Pausen (25-30 min Intervalle)
     ↓
🔴 Reflexion (2 min) → Was wurde getan? Was bleibt?
     ↓
[Task schließen / Status aktualisieren]
```
