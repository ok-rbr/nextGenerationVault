# [[zettelkasten_para_flow]]

## Key Concepts

**Zettelkasten** und **PARA** sind komplementäre Systeme:

- **PARA** beantwortet: *Wo liegt die Information?* (Ablagestruktur)
- **Zettelkasten** beantwortet: *Wie vernetze ich Wissen?* (Denkstruktur)

### Der Wissensfluss: CODE + Zettelkasten

```
CAPTURE → ORGANIZE → DISTILL → EXPRESS
   ↓           ↓          ↓         ↓
[Inbox]   [PARA-Kat.] [Atomic]  [Permanent]
```

### Schritt für Schritt im Vault

```
00_inbox/          ← Capture: rohe Idee landet hier
      ↓
(Review: wohin gehört es?)
      ├──→ 01_projects/   (Projekt-relevant)
      ├──→ 02_areas/      (Bereich-relevant)
      ├──→ 03_resources/  (Ressource)
      └──→ 00_knowledge/
               ↓
          02_literature/  ← Organize: Quelle dokumentieren
               ↓
          01_atomic/      ← Distill: eine Idee, eine Note
               ↓
          03_permanent/   ← Express: vernetzte, verifizierte Erkenntnis
```

### Prinzipien der Verbindung

| Zettelkasten-Prinzip | PARA-Entsprechung |
|---|---|
| Inbox – rohe Erfassung | `00_inbox/` |
| Atomic – eine Idee | `01_atomic/` |
| Literature – Quellenbezug | `02_literature/` |
| Permanent – vernetztes Wissen | `03_permanent/` |
