# Project examples (Obsidian)

Only the fictional Elden Ring example templates are shared in this directory.
Personal, customer and real project templates belong on your machine and must
not be committed. The root `.gitignore` ignores newly created Markdown
templates here unless explicitly reviewed and allowlisted.

For work projects in Neovim, use the separate generic skeletons in
`99_system/015_templates/01_projects/default/` via `:NoteProjectCreate`.
Neovim cannot execute Obsidian Templater scripts. The command creates local
client/project indexes and project-specific templates, all of which are ignored.
Work notes follow `01_projects/<client_slug>/<project_slug>/`.

See the root `README.md` for vault setup and the distinction between work and
personal data.
