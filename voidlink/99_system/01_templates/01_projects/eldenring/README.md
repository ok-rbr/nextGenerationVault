Elden Ring Templates

Location: 01_templates/eldenring

This folder contains Markdown templates with YAML frontmatter for sessions, persons, items, boss encounters, builds, and quests.

Frontmatter keys are explicit; replace the empty strings or arrays with your values. Example placeholders use {{variable}} — if you use a Lua-based renderer (e.g., in Neovim/Chezmoi), adapt placeholders to your templating engine.

If you prefer chezmoi-based templates, place equivalents under ~/.local/share/chezmoi/nvim and adapt to the expected template syntax.

Examples live in the examples/ subfolder.
